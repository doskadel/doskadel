# PATTERNS: рабочие правила DoskaDel

Уроки и процессы (без самобичевания, инциденты закрыты).

## Правки файлов (после инцидента 2026-10-04)

**Правило:** правки только через `edit_file` (точечно, с уникальным контекстом).

**Запрещено:** python-однострочники вида `open(p,'w').write(open(p).read()...)` — `open(w)` усекает файл ДО чтения, файл стирается. Дважды потеряли файлы (TaskController, recurrence.js и др.); восстановили из git, часть правок переписали вручную.

**Перед правкой моделей/критичных файлов:** `git status` должен быть чистым; если есть незакоммиченные правки — сначала коммит (wip-коммиты не стыдно, мелкие и частые).

**Массовая замена:** если нужно заменить в многих файлах — по одному через `edit_file`, либо отдельным скриптом, который ГАРАНТИРОВАННО читает до записи (сначала `s = read(f)`, потом `write(f, s.replace(...))`, в разных инструкциях).

## Тесты
- Тестовые скрипты должны чистить за собой ВСЕ коллекции (включая Status), иначе копится мусор. При падении — авто-очистка старых тестовых пользователей в начале прогона (см. test-isolation.js).
- Перед боевой миграцией — mongodump. Миграции идемпотентны, dry-run со счётчиками.

## .gitignore (инцидент 2026-10-04)
- Правило `scripts/` (без слэша в начале) матчит ЛЮБУЮ папку scripts на любой глубине → `backend/scripts/` (миграции, тесты) молча не попадало в git. Правильно: `/scripts/` (только корень) или не игнорировать рабочие скрипты.
- Проверка после добавления файлов: `git ls-files <path>` — если пусто, файлы не отслеживаются (даже если физически есть). `git check-ignore -v <file>` покажет правило.
- Миграции и тесты ДОЛЖНЫ быть в git (воспроизводимость на других инсталляциях).

## TipTap-редактор: грабли (2026-10-17)

- **Enter = hardBreak.** Если в StarterKit активен `hardBreak`, Enter вставляет `<br>` ВНУТРИ одного абзаца — из-за этого блочные команды (цитата, код, список, интервал) захватывают «всё выше». Фикс: `StarterKit.configure({ hardBreak: false })` + `normalizeDoc` для старых MD.
- **Дубли расширений.** StarterKit 3 уже включает `link`, `underline`, `codeBlock`, `gapcursor`, `trailingNode`. Повторное подключение даёт `Duplicate extension names` и непредсказуемые баги. Настраивать через `StarterKit.configure({ link: {...} })`, а не добавлять заново.
- **`setHorizontalRule`** сам вставляет по курсору (режет строку) и заменяет выделение — не нужен кастомный.
- **Клик по кнопкам тулбара** без `onMouseDown preventDefault` сбивает выделение → команда применяется не туда. Сохранять/восстанавливать selection.
- **Пустые абзацы — это точки для Gapcursor/TrailingNode.** Не удалять их «для чистоты».
- **Клик в пустоту справа/снизу от блока:** рабочий вариант — вставить пустой абзац ПОСЛЕ блока и встать в него. GapCursor («линия снаружи») визуально не удалось показать (нужен зазор между блоками + focused); в других редакторах (Notion) клик справа от блока тоже создаёт новый блок.
- **BlockNote** пробовали — это Notion-стиль БЕЗ панели кнопок (только `/` и всплывающие). Не подошёл: оператор хочет постоянную панель кнопок. Оставили TipTap.
- **Подсветка кода:** `@tiptap/extension-code-block-lowlight` (декорации ProseMirror) работает ТОЛЬКО в редакторе. Для просмотра — подсвечивать HTML постобработкой (lowlight + CSS `.hljs-*`), как в RichTextRenderer.
- **Mantine 9 требует React 19**; для React 18 — Mantine 8. (Если когда-то вернёмся к BlockNote.)

## Файлы/вложения (2026-10-18)

- **MinIO из Docker Hub удалён** (source-only, репозиторий архивирован). Замена — **Garage** (`dxflrs/garage`, тег+digest). S3-совместим, single-node через `server --single-node --default-bucket` + env `GARAGE_DEFAULT_ACCESS_KEY/SECRET_KEY/BUCKET`. `rpc_secret`/`admin_token` — только через env (`GARAGE_RPC_SECRET`, `GARAGE_ADMIN_TOKEN`), НЕ в git. Образ distroless — нет shell, entrypoint-скрипт не сделать.
- **Доступ к файлам — только backend-прокси** (multer→putObject, getObject→pipe). Не публиковать S3 наружу, не использовать presigned (CORS/SigV4-грабли с nginx). Тип файла определять по сигнатуре (`file-type@16`, CJS! v19+ — ESM-only). Текстовые без сигнатуры (txt/md/csv/json) — fallback по расширению.
- **Node 20 в контейнере**: `file-type@22` требует Node>=22, `@19` ESM-only → брать `16.x`. После смены версий в `package.json` — обновлять `package-lock.json` на хосте и пересобирать образ (анонимный volume `/app/node_modules` сохраняет старые пакеты между recreate).
- **min-height у редактора в flex-колонке**: без него `.rte` схлопывается под тулбаром на мобиле.
- **attachment:<id> в JSON**, не URL (TTL/хост). Просмотр — Image NodeView (fetch с Authorization → blob), в RichTextRenderer — после generateHTML заменять `img[src^=attachment:]` на React-корень (createRoot) + DOMPurify ALLOWED_URI_REGEXP для `attachment:`.
- **Удаление вложения из блока** должно чистить узлы из текста (`removeAttachmentFromJson`).
- **Вложения комментариев (Jira)**: принадлежат owner, помечены `commentId`; удаление комментария удаляет их из общего блока.

## Дерево комментариев (2026-10-18)

- Глубина: `parentId` = прямой родитель (без схлопывания), лимит 3 (на 3-м нет «Ответить», бэк отклоняет). Ответ — inline под узлом, не общим блоком внизу.
- **Инлайн-ответ**: `autoFocus` в `RichTextEditor` должен срабатывать ОДИН раз (ref-guard, эффект ПОСЛЕ `useEditor`), иначе курсор сбрасывается в начало при каждом рендере.
- **Быстрые тогглы чеклиста**: PUT с полным JSON по устаревшему пропсу затирает предыдущие → держать `checklistBase` ref (накопленный JSON) + сериализовать; не перечитывать модалку после каждого тоггла (дёрганье).
- **Зачёркивание чеклиста**: `data-checked` в TipTap может остаться `false` при визуальной галочке → дублировать правилом `li:has(input[type=checkbox]:checked)`.
- **Сепараторы комментариев**: у `.comment-item` есть `border-left`; горизонтальный — через `::before` (не `border-top`), иначе сливается с вертикальной линией. `--color-border` на тёмном фоне почти не виден — брать `--color-border-strong`.
- **Dev-сборка CRA + Service Worker** отдаёт старый CSS из кэша (Ctrl+F5 не помогает): в dev не регистрировать SW (`unregister`), при отладке стилей — Unregister + Clear site data.

## Подтверждение почты / Resend (2026-10-18)

- **Выбор модели:** мягкое подтверждение (регистрация активна сразу + баннер + статус в профиле). Жёсткий вариант (без входа до подтверждения) не выбран: нет трения, но можно регистрироваться на чужой адрес. Гибрид (ограничить пуши/смену пароля) — на будущее.
- **Resend:** бесплатно 3000 писем/мес, 100/день. Домен `mail.doskadel.ru` (поддомен) верифицирован: DKIM (TXT `resend._domainkey.mail`), SPF (CNAME `rsend.mail`), Return-Path (CNAME `send.mail`), DMARC (TXT `_dmarc.mail`, `v=DMARC1; p=none;`). Записи в Reg.ru (зона `doskadel.ru`, поэтому имена с `.mail`).
- **Ключ и from:** `RESEND_API_KEY`, `MAIL_FROM=DoskaDel <noreply@mail.doskadel.ru>`, `APP_URL=https://doskadel.ru`. Без ключа mailer — no-op (логирует), регистрация не падает.
- **Спам:** письма от нового домена часто попадают в «Спам» Яндекса — это норма, репутация набирается. Юзеру: «не спам» + добавить отправителя в контакты.
- **Токен:** 32 байта hex, срок 24ч, хранится в User (`emailVerifyToken`/`emailVerifyExpires`). Страница `/verify-email` — публичный маршрут (не под ProtectedRoute).

## Аналитика GA4 (2026-10-18)

- **Симптом:** 2-3 недели ноль, хотя запросы `collect` уходили (204). Причина — **неверный Measurement ID в коде** (`G-DL9PNLQ5V` вместо `G-DL9PNL0Q5V`): данные уходили в несуществующий ресурс. Сверять ID копированием из GA (Admin → Data Streams), не перепечатывать.
- **Consent Mode:** без `gtag('consent','default',{analytics_storage:'granted'})` GA4 может не отправлять данные. Добавлено.
- **Проверка:** DevTools → Network → `collect` (204 — норма), GA → Reports → **Realtime** (не обычные отчёты: задержка 24-48ч).

## Восстановление пароля (2026-10-18)

- Токен сброса: сырой (32 байта hex) — в письме, хэш sha256 — в БД (`resetPasswordToken`), срок 1ч. Так утечка БД не даёт рабочую ссылку.
- `forgot-password` всегда отвечает 200 (не раскрывать существование аккаунта), rate-limit.
- `reset-password` после смены отзывает ВСЕ refresh-сессии (`RefreshToken.deleteMany`) — защита при угоне.
- Пароль хэшируется pre-save hook в User — достаточно `user.password = new; save()`.
- Страницы forgot/reset — на `AuthLayout` (как Login), ссылка «Вернуться» — в footer. Пароль — через `PasswordInput` (глазок), не голый input.
- E2E локально: forgot → хэш в БД → reset → login новым паролем.

- Порт 27017 на проде **не проброшен** (закрыт после взлома). IP может меняться при пересоздании контейнера.
