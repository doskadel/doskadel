# PROJECT: WorkList (DoskaDel)

Состояние проекта для агента. Обновлено: 2026-10-03.

## Что это
Кроссплатформенное приложение для задач и базы знаний: канбан+список, повторяющиеся задачи с подтверждениями, Web Push, PWA, офлайн. Аккаунт, синхронизация между устройствами.

**Прод:** работает (сервер + веб). **Git:** github.com/doskadel/doskadel, ветка main.

## Стек
- **Backend:** Node 20, Express 4, MongoDB 7 (Mongoose 7), JWT, Agenda 5 (планировщик), web-push 3. Хелмет, CORS, rate-limit, express-validator.
- **Frontend:** React 18, TypeScript 4.9, CRA 5, react-router 6, axios, @dnd-kit (канбан), Service Worker + Push API. Стили — CSS-переменные. MUI+emotion в package.json, но в src/ НЕ используются (мёртвая зависимость, проверено).
- **Docker:** backend:5000, frontend:3000, mongo:27017 (docker-compose.yml).
- **Тесты:** НЕТ. jest+supertest в зависимостях, но ни одного *.test в репо (проверено).

## Что сделано (этапы 1-12)
Аутентификация (JWT, bcrypt), задачи (канбан drag-n-drop, список, статусы, приоритеты, сроки UTC), повторяющиеся задачи (daily/weekly/monthly, подтверждения, лимит 100 вхождений), Web Push (Desktop/Android/iOS-PWA), база знаний (статьи), глобальный поиск (command palette), дашборд, профиль+настройки уведомлений, PWA.

## Что не сделано
- Этап 13: синхронизация данных (реальное время, WebSocket — в перспективе).
- Этап 14: чат-бот / ассистент (текст/голос).

## Планы (из PROJECT_PLAN.md)
- Функционал: связи задачи↔статьи, Markdown-таблицы в статьях, «прекратить повторение».
- UX: тёмная тема, иконки (lucide-react), мобильный адаптив.
- Перспектива: i18n (RU/EN), экспорт данных.
- **Техдолг:** CRA 5 → Vite, ограничить CORS для прода, VAPID-ключи из .env.example.

## Изменения 2026-10-03 (подробности: git log, decisions.md)
- **Auth:** access в памяти JS, refresh в httpOnly cookie (SameSite=Lax, Secure в проде), reuse-detection с отзывом семьи, проверка Origin на refresh/logout, cookie-parser, authLimiter на логин. Dev: CRA proxy на /api (один origin).
- **Статусы:** добавлен системный ключ Status.key, миграция migrate-status-keys.js применена.
- **UI:** tokens.css и useTheme.ts (темы), lucide-react, настройки дашборда (тогглы блоков, порядок, поле количества), выровнены заголовки блоков без иконок, ряд кнопок Главной в одну строку (46px).
- **Решения оператора:** личное использование и малые команды, без мультитенантности; запросы к данным через единый слой (позже workspaceId); бот в проде через серверный API, изменения только через превью с подтверждением; drag на самом дашборде и виджеты отклонены, порядок блоков только в настройках.

## Риски перед продом
- Reverse-proxy и HTTPS не настроены: без них Secure-cookie не встанет, в проде нужен nginx/Caddy (/ фронт, /api бэк).
- RefreshToken: поля family/used добавлены без миграции, старые токены без family не защищены reuse-detection (истекают за 30 дней).
- Правки дашборда (отступы, кнопки) проверены оператором на телефоне, автоматически не измерялись (Playwright не держит cookie-сессию).
- Прод не деплоился, ломающих изменений нет.
