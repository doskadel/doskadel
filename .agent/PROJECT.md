# PROJECT: WorkList (DoskaDel)

Состояние проекта для агента. Обновлено: 2026-10-02.

## Что это
Кроссплатформенное приложение для задач и базы знаний: канбан+список, повторяющиеся задачи с подтверждениями, Web Push, PWA, офлайн. Аккаунт, синхронизация между устройствами.

**Прод:** работает (сервер + веб). **Git:** github.com/doskadel/doskadel, ветка main.

## Стек
- **Backend:** Node 20, Express 4, MongoDB 7 (Mongoose 7), JWT, Agenda 5 (планировщик), web-push 3. Хелмет, CORS, rate-limit, express-validator.
- **Frontend:** React 18, TypeScript 4.9, CRA 5, react-router 6, axios, @dnd-kit (канбан), Service Worker + Push API. Стили — CSS-переменные. MUI+emotion в package.json, но в src/ НЕ используются (мёртвая зависимость, проверено).
- **Docker:** backend:5000, frontend:3000, mongo:27017 (docker-compose.yml).
- **Тесты:** НЕТ. jest+supertest в зависимостях, но ни одного *.test в репо (проверено).

## Что сделано (этапы 1-12)
Аутентификация (JWT, bcrypt), задачи (канбан drag-n-drop, список, статусы, приоритеты, сроки UTC), повторяющиеся задачи (daily/weekly/monthly, подтверждения, лимит 100 вхождений), Web Push (Desktop/Android/iOS-PWA), база знаний (статьи), глобальный поиск (command palette), дашборд, профиль+настройки уведомлений, PWA.

## Что не сделано

- Этап 14: чат-бот / ассистент (текст/голос).

## Как работать
Полный регламент проекта: **RULES.md**. Кратко:
- Оператор ставит задачу → ярус 2 (DeepSeek) делает до конца сам.
- Ярус 1 (Claude) — только сложное/архитектурное.
- Оператор проверяет готовую фичу.
- Merge/push в main: DeepSeek и Claude могут сами. Деплой на прод — только с апрува оператора.
- Вопросы к Клоду: .agent/QUESTIONS.md. Видение: VISION.md. Баги: BUGS.md.
- Ассеты: C:/projects/_assets (найти/сгенерировать → provenance → применить).
