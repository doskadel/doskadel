Также: скрипт scripts/delete-user-by-email.js (каскадное удаление юзера по email, dry-run).

Вложения комментариев принадлежат owner, удаление комментария чистит файлы.
  - Теги: модель Tag (unique workspace+nameLower), tagIds в Task/Article, API (list/create/update/delete/merge), фильтр в панели фильтров (MultiSelect + Любой/Все), поиск по тегам (локальный и глобальный, срез '#').

  - Комментарии: модель Comment (дерево до 3 уровней, soft delete с каскадом потомков), TipTap-редактор (урезанный тулбар), вложения (Jira-style), автор с аватаром+email, inline-ответ, очистка после отправки, свёрнутое поле ввода.
  - UI: EntityLayout (aside «Информация о задаче/статье»: статус/приоритет/теги/даты; на мобиле свёрнут), кнопки save в footer, сворачиваемый тулбар (по умолчанию свёрнут), чеклисты с зачёркиванием и мгновенным сохранением в просмотре, аватар (кроп) в профиле и шапке.
  - Тесты бэка: 53 зелёных (tags/links/comments + существующие), jest --runInBand.
