## v1.3.0 (2026-10-17)

**Ключевое:**
- **ИСПРАВЛЕН корень багов редактора** — Enter создавал `hardBreak` внутри абзаца. Отключён `hardBreak` в StarterKit → Enter = новый абзац. Разом починились: цитата, код, списки, межстрочный интервал (применяются к текущей строке, а не ко всему блоку).
- **Цвет текста и фона** (только выделенного фрагмента), общая палитра 30 цветов, свой цвет, сброс.
- **Красивые диалоги** для ссылки (адрес + текст, удаление) и картинки по URL — вместо системного prompt.
- **Код/цитата по выделению** — объединяют несколько абзацев в один блок (а не по блоку на каждый); повторное нажатие снимает; код при снятии разбивается по строкам на абзацы.
- **Курсор за любым блоком**: перестали удалять пустые абзацы (это точки для Gapcursor/TrailingNode).

**Известное ограничение:** после вставки код-блока курсор может оказаться не в нём (косметика, клик в блок решает).

## v1.2.1 (2026-10-17)

**Что вошло:**
- Межстрочный интервал (1.0 / 1.5 / 2.0), дефолт 1.5; показывается в тулбаре, применяется к текущему абзацу/выделению.
- Клик по кнопкам тулбара больше не сбивает курсор (сохранение/восстановление выделения) — цитата/код/список применяются к текущей строке.
- Панель таблицы: единые «+ / −» для строк и столбцов, корзина только для всей таблицы.
- Убраны дубли расширений link/underline (конфликтовали со StarterKit).

**Известное ограничение (не решено):** Enter в редакторе создаёт `hardBreak` внутри одного абзаца (а не новый абзац). Из-за этого блочные команды (цитата, код, список, интервал) применяются ко всему визуальному блоку целиком. Пробовали: normalize MD, кастомное расширение Enter (priority 1000), handleKeyDown в editorProps — не помогло. Оставлено как есть (оператор согласен: сам факт смены интервала уже полезен). Причина Enter=hardBreak не найдена (возможно, tiptap-markdown breaks:true через keymap).

## v1.2.0 (2026-10-17)

**Что вошло:**
- **WYSIWYG-редактор статей (TipTap)** — вместо Markdown-текста. Обычный юзер не должен знать Markdown: нажимаешь кнопку — получаешь результат.
- Тулбар: заголовки, жирный/курсив/подчёркнутый/зачёркнутый, списки (маркированный, нумерованный, чеклист), цитата, код, разделитель, ссылка, картинка, **таблица**.
- **Таблицы:** вставка, +/− строки/столбцы, изменение ширины столбца (тянуть), изменение высоты строки (тянуть), горизонтальное и вертикальное выравнивание содержимого, цветовая разметка.
- **Гибридное хранение** (ADR 2026-10-16): contentJson (TipTap JSON) — источник правды, content (Markdown) — производное для поиска/совместимости. Старые статьи работают, конвертируются лениво при редактировании.
- Безопасный рендер: generateHTML + DOMPurify.

**Техническое:** TipTap 3.32, tiptap-markdown, DOMPurify; кастомные расширения (вертикальное выравнивание ячеек, высота строк), ProseMirror-плагин resize строк; запрет drag-перетаскивания текста внутри ячеек.

**План 1.3.0:** вложения/файлы (MinIO), картинки в тексте с полноэкранным просмотром (zoom/pan).

## v1.1.0 (2026-10-16)

**Что вошло:**
- Форматирование текста в статьях: Markdown-редактор (заголовки, списки, чеклисты, таблицы, код, ссылки, картинки) + режим «Просмотр».
- Статьи рендерятся с форматированием (заголовки, таблицы, код, цитаты, ссылки).
- Модалки статей — почти во всю ширину экрана; редактор выше.
- Превью в списках/поиске — очистка Markdown до простого текста.
- Бэкапы прода (Фаза 0): ежедневный mongodump + cron + проверка восстановления (инфраструктура, не UI).

**Техническое:** react-markdown + remark-gfm + remark-breaks, @uiw/react-md-editor, stripMarkdown.

**План 1.2.0:** WYSIWYG-редактор (TipTap) вместо Markdown — обычный юзер не должен знать Markdown; таблица по кнопке с +строка/+столбец; гибридное хранение (contentJson + производный MD). Решение согласовано (ADR 2026-10-16).

## v1.0.0 — первый публичный релиз (2026-10-14)

**Что вошло:**
- Аутентификация: вход/регистрация, JWT + refresh-сессии (надёжный вход, «помни меня», выход со всех устройств), смена пароля.
- Задачи: списком, на доске (канбан), в календаре; статусы, приоритеты, сроки.
- Повторяющиеся задачи: daily/weekly/monthly, напоминания, подтверждения вхождений, история, «перенести/завершить», финальный статус (пауза/закрытие серии).
- База знаний: статьи, поиск по ним.
- Глобальный поиск (Ctrl/Cmd+K), дашборд (сроки/статусы/последние).
- PWA: установка на телефон, Web Push.
- Темы: тёмная и светлая.
- SEO: robots, sitemap, OG, JSON-LD, Google Analytics.
- Кроссплатформенность: телефон, планшет, ПК; синхронизация между устройствами.

**Известные ограничения / не в этой версии:**
- Форматирование текста (Markdown) в задачах и статьях — план 1.1.0.
- Вложения (файлы, картинки в тексте) — план 1.1.0.
- Теги, связи задача↔статья — план 1.2.0.

## Как повышать версию

1. Определить тип: MAJOR / MINOR / PATCH.
2. Обновить `frontend/package.json`, `backend/package.json`, `frontend/src/utils/support.ts` (APP_VERSION).
3. Добавить запись в этот файл (сверху): версия, дата, что вошло.
4. Закоммитить с сообщением `release: vX.Y.Z — <кратко>`.
5. Для анонса — взять из этой записи «Что вошло» и написать пост.
