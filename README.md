# WorkList - Приложение для управления задачами и дневником

## Описание проекта

WorkList - это кроссплатформенное приложение для управления задачами и ведения дневника с синхронизацией данных между браузером и мобильным устройством. Приложение позволяет:

- Управлять задачами (создание, редактирование, удаление, изменение статуса)
- Вести дневник/справочник с функцией поиска и фильтрации записей
- Синхронизировать данные между браузером и мобильным приложением через аккаунт
- Использовать встроенный чат-бот для работы с данными через текстовые и голосовые команды

## Особенности

### Основные функции:
- Главный экран с поиском по ключевым словам
- Список совпадений с возможностью перехода к нужному экрану
- Управление задачами с различными статусами
- Ведение дневника/справочника с полным текстовым поиском
- Фильтрация записей по содержимому

### Технические особенности:
- Кроссплатформенная архитектура (браузер + мобильное приложение)
- Синхронизация данных между устройствами
- Встроенный чат-бот для работы с данными
- Поддержка голосовых команд

## Архитектура

Проект использует микросервисную архитектуру с отдельными контейнерами для:
- **Backend** - серверная часть на Node.js/Express
- **Frontend** - клиентская часть (веб-приложение)
- **Database** - база данных (MongoDB)

## Технологии

### Backend:
- Node.js
- Express.js
- MongoDB
- Docker

### Frontend:
- React.js
- TypeScript
- Material-UI

### Дополнительно:
- Docker для контейнеризации
- JWT для аутентификации
- WebSockets для реального времени

## Запуск проекта

### Требования:
- Docker
- Docker Compose

### Локальный запуск:

1. Клонируйте репозиторий
2. Выполните команду: `docker-compose up`
3. Приложение будет доступно по адресу: `http://localhost:3000`
